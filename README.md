## Témakör
* Közösségi Eszközkölcsönző és Foglalási Webalkalmazás
Desc:
* társasházak, kollégiumok és kisebb közösségek tagjai átláthatóan kölcsön tudják adni, letudják foglaglni és nyomon tudják követni a ritkán használt eszközeiket. Felhasználók feltölt képeket a tárgyról és leírást róla plussz az állapotát, a userek pedig kibérelhetik egy fix időre és értékelhetik az adott terméket/felhasználót. Szűrővel rátudnak kereseni hogy milyen termékkategóriát keresnek és hogy mi a max távolság amit mutasson a szűrő.  

---
## Való életbeli probléma megoldás
* Az emberek akik bizonyos eszközeiket ritkán használják feltehetik, hogy másoknak akiknek kellhet kibéreljék egy adott időre. Ezáltal aki keres, annak nem kell új eszközt vennie. Aki meg bérbeadja nem fogja úgy érezni hogy feleslegesen foglalja a helyet.
* Nyilván ez felveti a kérdést hogy mitörténik akkor ha az adott tárgy tönkremegy vagy nem olyan minőségű a termék mint ami a leírásban szerepelt/képeken volt. (ToS, ez csak egy digitális közvetítő platform, a "szerződés" a berlő és a bérbeadó között történik, a platform csak egy központosított helyként szolgál)
  
## Technológiai Stack
* **Frontend:** React + TypeScript (React a Framework elvárást teljesíti.)
* **Backend:** PHP (Restful API elvárást telejsíti)
* **Adatbázis:** MySQL (A relációs adatbázis kikötést teljesíti. Adatokat tárol és kezel.)
